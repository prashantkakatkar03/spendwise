\# SpendWise Data Model \& Database Structure 🗄️



\## Purpose



The SpendWise data model defines how user financial information is stored, organized, and connected. It helps the system track transactions, analyze spending patterns, apply rules, and generate personalized recommendations.



\---



\# 1. User Table 👤



\## Purpose



Stores basic user information and financial preferences.



\## Fields



| Field Name | Description |

|------------|-------------|

| User\_ID | Unique identifier for each user |

| Name | User full name |

| Email | User email address |

| Mobile\_Number | User contact number |

| Currency | Preferred currency |

| Created\_Date | Account creation date |



\## Example



User\_ID: U001  

Name: Prashant  

Currency: INR



\---



\# 2. Account Table 🏦



\## Purpose



Stores user's bank accounts, wallets, and financial accounts.



\## Fields



| Field Name | Description |

|------------|-------------|

| Account\_ID | Unique account identifier |

| User\_ID | Linked user |

| Bank\_Name | Bank or financial institution |

| Account\_Type | Savings, Current, Credit Card, Wallet |

| Account\_Number | Masked account number |

| Current\_Balance | Available balance |



\## Example



Account\_ID: A001  

Bank\_Name: HDFC  

Account\_Type: Savings



\---



\# 3. Transaction Table 💳



\## Purpose



Stores all financial transactions received from bank accounts or manual entries.



\## Fields



| Field Name | Description |

|------------|-------------|

| Transaction\_ID | Unique transaction identifier |

| Account\_ID | Related account |

| Date | Transaction date |

| Description | Bank transaction description |

| Merchant\_Name | Transaction merchant |

| Amount | Transaction amount |

| Transaction\_Type | Income, Expense, Transfer |

| Category\_ID | Expense category |

| Payment\_Mode | UPI, Card, Cash, Net Banking |



\## Example



Transaction\_ID: T001  

Merchant: Amazon  

Amount: ₹2500  

Type: Expense



\---



\# 4. Category Table 🏷️



\## Purpose



Stores expense and income categories.



\## Fields



| Field Name | Description |

|------------|-------------|

| Category\_ID | Unique category ID |

| Category\_Name | Category name |

| Category\_Type | Income or Expense |



\## Examples



Expense Categories:



\- Food

\- Shopping

\- Travel

\- Entertainment

\- Healthcare

\- Bills



Income Categories:



\- Salary

\- Freelance

\- Investment



\---



\# 5. Rule Engine Table ⚙️



\## Purpose



Stores SpendWise financial intelligence rules.



\## Fields



| Field Name | Description |

|------------|-------------|

| Rule\_ID | Unique rule identifier |

| Rule\_Name | Name of rule |

| Condition | Rule trigger condition |

| Action | Action performed |

| Priority | Execution priority |

| Status | Active/Inactive |



\## Example



Rule\_ID: R005



Rule\_Name:

Self Transfer Detection



Action:

Classify transaction as Self Transfer



Priority:

1



\---



\# 6. Recommendation Table 💡



\## Purpose



Stores financial suggestions generated by SpendWise.



\## Fields



| Field Name | Description |

|------------|-------------|

| Recommendation\_ID | Unique ID |

| User\_ID | User receiving recommendation |

| Rule\_ID | Rule that generated suggestion |

| Message | Recommendation text |

| Date | Generated date |

| Status | Read/Unread |



\## Example



Recommendation:



"Compare prices before online shopping to save money."



\---



\# 7. Financial Goal Table 🎯



\## Purpose



Stores user's financial goals and progress.



\## Fields



| Field Name | Description |

|------------|-------------|

| Goal\_ID | Unique goal ID |

| User\_ID | Linked user |

| Goal\_Name | Goal description |

| Target\_Amount | Required amount |

| Saved\_Amount | Current savings |

| Target\_Date | Completion date |

| Status | Active/Completed |



\## Example



Goal:



Emergency Fund



Target:



₹1,00,000



Saved:



₹40,000
