\# SpendWise Database Schema 🗄️



\## Purpose



The SpendWise database schema defines how financial data is stored, connected, and processed.



It supports:



\- User financial tracking

\- Transaction management

\- Expense categorization

\- Rule engine processing

\- Financial recommendations

\- Budget management

\- Goal tracking



\---



\# Database Entities Overview



Main Database Tables:



1\. Users

2\. Accounts

3\. Transactions

4\. Categories

5\. Rules

6\. Recommendations

7\. Financial Goals

8\. Budgets



\---



\# 1. Users Table 👤



\## Table Name



`users`



\## Purpose



Stores user profile information.



\## Schema



| Column Name | Data Type | Key | Description |

|---|---|---|---|

| user\_id | INT | Primary Key | Unique user identifier |

| name | VARCHAR | | User name |

| email | VARCHAR | Unique | User email |

| mobile\_number | VARCHAR | | Contact number |

| currency | VARCHAR | | Preferred currency |

| created\_date | DATE | | Account creation date |



\## Example



```

User\_ID: 1

Name: Prashant

Currency: INR

```



\---



\# 2. Accounts Table 🏦



\## Table Name



`accounts`



\## Purpose



Stores user's bank accounts and financial accounts.



\## Schema



| Column Name | Data Type | Key | Description |

|---|---|---|---|

| account\_id | INT | Primary Key | Account identifier |

| user\_id | INT | Foreign Key | Linked user |

| bank\_name | VARCHAR | | Bank name |

| account\_type | VARCHAR | | Savings/Credit Card/Wallet |

| account\_number | VARCHAR | | Masked account number |

| current\_balance | DECIMAL | | Current balance |



\## Relationship



One user can have multiple accounts.



```

Users (1) -------- (Many) Accounts

```



\---



\# 3. Transactions Table 💳



\## Table Name



`transactions`



\## Purpose



Stores all financial transactions.



\## Schema



| Column Name | Data Type | Key | Description |

|---|---|---|---|

| transaction\_id | INT | Primary Key | Transaction identifier |

| account\_id | INT | Foreign Key | Related account |

| category\_id | INT | Foreign Key | Transaction category |

| date | DATE | | Transaction date |

| description | TEXT | | Bank description |

| merchant\_name | VARCHAR | | Merchant name |

| amount | DECIMAL | | Transaction amount |

| transaction\_type | VARCHAR | | Income/Expense/Transfer |

| payment\_mode | VARCHAR | | UPI/Card/Cash |



\## Relationship



```

Accounts (1) -------- (Many) Transactions

```

\# 6. Recommendations Table 💡



\## Table Name

\## Schema

|---|---|---|---|

| user\_id | INT | Foreign Key | User |
